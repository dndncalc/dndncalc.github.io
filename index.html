이 사이트는요

복잡한 연금 기준이나 날짜 계산을 누구나 쉽게 할 수 있도록 만든 무료 계산기 모음이에요. 글씨를 크게, 설명은 쉽게 썼어요. 계산에 쓰는 기준은 국민연금공단, 보건복지부 같은 공식 자료를 바탕으로 하고, 기준이 바뀌면 고쳐서 날짜를 적어 둬요.

어떤 자료를 근거로 쓰고 어떻게 확인·수정하는지는 편집 원칙에 정리해 두었어요. 계산기와 생활 안내 글 목록은 생활 안내에서도 볼 수 있어요.

누구를 위한 사이트인가요

연금 받을 나이, 퇴직금, 실업급여처럼 50대·60대가 되면 갑자기 챙길 계산이 많아져요. 든든 생활계산기는 그런 분들을 먼저 생각하고 만들었어요. 정부 누리집의 작은 글씨와 어려운 말 때문에 읽다 지친 분, 부모님 연금을 대신 알아보는 자녀분도 쉽게 쓰실 수 있어요.

  • 큰 글씨: 계산 결과는 화면에서 가장 큰 글씨로 보여 드려요.
  • 쉬운 말: '지급개시연령' 같은 말 대신 '받기 시작하는 나이'처럼 풀어 썼어요.
  • 가입·설치 없이: 회원가입이나 앱 설치 없이 바로 써요. 넣은 숫자는 내 기기 안에서만 계산해요.
  • 근거와 날짜: 페이지마다 참고한 공식 자료와 확인한 날짜를 적어 둬요.

이렇게 쓰세요

  1. 위 '주제별로 찾기'에서 번호를 누르거나, 아래 표에서 필요한 계산기를 골라요.
  2. 칸에 태어난 해, 날짜, 금액을 넣어요. 예시 날짜가 들어 있으면 눌러서 내 날짜로 바꿔요. 원 단위 금액 칸 아래에는 '= 900만 원'처럼 읽기 쉽게 다시 보여 드려요.
  3. 초록색 계산 버튼을 눌러요. 결과가 화면 아래에 생기면 결과가 있는 곳으로 저절로 내려가요.
  4. 결과 아래의 '먼저 보는 답', 표, 자주 묻는 질문으로 내 상황을 한 번 더 확인하고, 신청은 안내한 공식 누리집에서 해요.

자주 묻는 질문

든든 생활계산기는 돈을 내야 하나요?
아니요. 모든 계산기와 안내 글은 무료이고, 회원가입이나 앱 설치 없이 바로 쓸 수 있어요.
넣은 생년월일이나 금액이 어딘가에 저장되나요?
계산은 쓰시는 휴대폰이나 컴퓨터 안에서만 하고, 넣은 숫자는 서버로 보내거나 저장하지 않아요.
계산 결과를 그대로 믿어도 되나요?
공식 자료의 기준으로 계산하지만 참고용이에요. 실제 금액과 날짜는 가입 기간, 소득, 가족 상황에 따라 달라질 수 있으니 신청이나 계약 같은 중요한 일은 해당 기관에 꼭 확인하세요.
제도가 바뀌면 내용도 고쳐지나요?
제도나 금액이 바뀌면 공식 자료를 다시 확인해 고치고, 각 페이지 아래 작성·수정 안내에 고친 날짜와 내용을 적어 둬요.
글씨가 작게 보이면 어떻게 하나요?
휴대폰에서는 두 손가락으로 화면을 벌리면 커지고, 컴퓨터에서는 Ctrl 키를 누른 채 + 키를 누르면 커져요. 원래대로 돌릴 때는 Ctrl 키와 0을 함께 눌러요.
틀린 내용을 발견하면 어디에 알리나요?
각 페이지 아래 오류·변경 알리기 버튼이나 문의하기 페이지로 알려 주세요. 확인한 뒤 고치고 수정한 날짜를 적어 둘게요.
